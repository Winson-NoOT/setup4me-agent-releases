# Setup4Me Agent releases

This repository distributes Setup4Me Agent installers and SHA-256 checksums. Workflow repositories remain under their owners' control.

Download the package for your computer from [Releases](https://github.com/Winson-NoOT/setup4me-agent-releases/releases). Windows uses the EXE installer; macOS uses the universal DMG; Linux offers a Debian/Ubuntu package and an AppImage.

Install the agent once, connect your browser, then start approved setups directly from [Setup4Me Marketplace](https://setup4me.com). The agent runs in the system tray or menu bar. Python is not required.

The initial packages are unsigned. Platform signing and macOS notarization are not yet configured.
